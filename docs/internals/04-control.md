# 04. ファン制御アルゴリズム

## 制御モード一覧

`pmgfand` は以下の 5 つの動作モードをサポートする。

| モード | 内部識別子 | 説明 |
|---|---|---|
| **iRMC Auto** | `irmc_auto` | OEM 強制を解除し、iRMC S5 本来の自動制御へ委ねる（標準・安全退避先） |
| **Fixed PWM** | `fixed_pwm` | 指定した PWM%（0〜100%）に固定 |
| **Curve** | `curve` | 設定ファイルで定義された温度ファンカーブによる自動追従 |
| **Target RPM** | `target_rpm` | 指定した基準ファンの目標回転数（RPM）に一致させる閉ループ PI 制御 |
| **Calibrate** | `calibrate` | PWM 10%〜100% の各回転数を自動走査し、特性マップを作成する計測モード |

---

## 制御レート制限とヒステリシス

ファンの回転数が急激に変動すると、耳障りな風切り音（ハンチング）が発生し、ファンの軸受けにも負担がかかる。
そのため、制御エンジンは **「冷却方向は素早く、静音（減速）方向はゆっくり」** を基本原則として以下のレート制限を適用する。

1. **`step_up` (上昇幅制限)**:
   1回の制御サイクルで許容する PWM 上昇の上限値（例: 20%）。急な温度スパイクにも速やかに追従する。
2. **`step_down` (下降幅制限)**:
   1回の制御サイクルで許容する PWM 下降の上限値（例: 5%）。温度が下がってもファンは緩やかに減速させる。
3. **`down_hysteresis` (減速ヒステリシス)**:
   前回の PWM からの降圧要求差がこの値（例: 5%）未満の場合は、減速を保留して回転数を維持する。
4. **`min_apply_interval_ms` (最小適用間隔)**:
   ハードウェアへの PWM 書き込み頻度を制限（例: 5000ms）。過度な書き込みによる制御のバタつきを防止。

## ファンカーブ評価アルゴリズム (`crates/core/src/curve.rs`)

### 1. 区分線形補間
設定ファイルで定義された `points = [[T1, P1], [T2, P2], ...]` に基づき、現在の温度 $T$ から要求 PWM を算出する。
- $T \le T_1$: $P_1$
- $T \ge T_n$: $P_n$
- $T_i \le T < T_{i+1}$:
  $$PWM = P_i + (P_{i+1} - P_i) \cdot \frac{T - T_i}{T_{i+1} - T_i}$$

### 2. 複数カーブの最大値調停 (Max Selection)
CPU パッケージ温度や PCH 温度など、複数のカーブが定義されている場合、エンジンは各カーブの評価値を計算し、**最も高い PWM 値（最も冷却を求めている側の要求）を最終採用**する。

## Target RPM PI コントローラ (`crates/core/src/control.rs`)

目標回転数 $RPM_{target}$ に対して、現在の実測回転数 $RPM_{current}$ から最適な PWM を算出する。
微分項（D項）はノイズに弱くファン制御では不要なため、PI（比例・積分）制御を採用。

### 1. 不感帯 (Deadband)
$$\text{誤差 } e(t) = RPM_{target} - RPM_{current}$$
$$|e(t)| \le \text{deadband} \implies e(t) = 0$$
回転数が目標値付近（例: ±75 RPM 以内）にあるときは PWM を変更せず、安定した静音性を維持する。

### 2. PI 計算式
$$P(t) = K_p \cdot e(t)$$
$$I(t) = I(t-1) + K_i \cdot e(t)$$
$$PWM_{raw}(t) = PWM_{base} + P(t) + I(t)$$

- **抗ワインドアップ (Anti-Windup)**:
  出力 PWM が `min_pwm` または `max_pwm` で飽和した際、積分項 $I(t)$ の蓄積を即座に停止（クランプ）し、飽和解除後のオーバーシュートを防ぐ。
- **安全退避**:
  基準ファン（`reference_fan`）の回転数が読み取れなくなった場合、コントローラは安全のため直ちに `iRMC Auto` モードへ自動退避する。

## 自動キャリブレーション (`calibrate`)

ファンの PWM と回転数の関係は個体や周囲温度、エアフロー抵抗によって異なる。高精度な制御を行うため、自動測定ルーチンを実装している。

1. **掃引手順**:
   - PWM を 10% から 100% まで 10% 刻みで順次設定。
   - 各ステップでファンの回転数が整定するまで待機（スピンアップ時間確保）。
   - 一定時間の回転数をサンプリングし、中央値（Median）をその PWM の代表 RPM として記録。
2. **データの永続化**:
   - 計測結果は `/var/lib/pmgfand/calibration.toml` に保存される。
   - `Target RPM` モード開始時、目標回転数に近い初期 PWM をこのファイルから逆引き（区分線形補間）して初期値とするため、即座に目標回転数近辺に収束する。
3. **安全機能**:
   - キャリブレーション中にモード変更コマンド（`pmgfanctl auto` など）を受信した場合、直ちに測定を安全に中断。
   - 計測が正常終了すると、キャリブレーション開始前の元の制御モードへ自動的に復帰する。
