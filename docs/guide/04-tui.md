# TUI 操作ガイド (`pmgfanctl tui`)

`pmgfanctl` は、Ratatui を採用したリッチなターミナルユーザーインターフェース（TUI）を備えています。
現在のファン回転数・温度・制御状態をグラフィカルに監視しながら、キーボード操作で直感的にモード変更や設定を行えます。

---

## 起動方法

```bash
# TTY 接続時なら単体起動で TUI になります
pmgfanctl

# または明示的にサブコマンドを指定
pmgfanctl tui
```

> [!NOTE]
> **TUI を終了してもファンの制御は継続します**  
> 制御を行っている本体はバックグラウンドの systemd サービス（`pmgfand`）です。TUI は監視・操作を行う「リモコン」に過ぎないため、TUI を閉じてもサーバーのファン制御が途切れることはありません。

---

## 画面構成

ターミナル全体に以下のようなレイアウトが表示されます：

```text

│ Target: PRIMERGY TX1320 M4 | Backend: IPMI (open) | Safety: Normal │
├────────────────────────────────┬───────────────────────────────────┤
│ Fans                           │ Temperatures                      │
│                                │                                   │
│ FAN CPU    [ 1450 RPM ]   28%  │ CPU Package   [ 42.0 °C ]         │
│ FAN1 SYS   [ 1280 RPM ]   25%  │ PCH           [ 54.0 °C ]         │
│ FAN PSU1   [ 1620 RPM ] (Auto) │ NVMe Drive    [ 38.0 °C ]         │
│ FAN PSU2   [ 1590 RPM ] (Auto) │                                   │
├────────────────────────────────┴───────────────────────────────────┤
│ Control Status & Fan Curve                                         │
│ Mode: Curve | Current PWM: 25% | Scope: Chassis                    │
│                                                                    │
│  100% ┤                                            ╭──             │
│   75% ┤                                       ╭────╯               │
│   50% ┤                              ╭────────╯                    │
│   25% ┤                   ╭──────────╯                             │
│    0% ┼───────────────────┴────────────────────────────            │
│       30°C      45°C      60°C      75°C      90°C                 │
├────────────────────────────────────────────────────────────────────┤
│ [A] Auto  [C] Curve  [F] Fixed PWM  [R] Target RPM  [S] Scope  [Q] │
└────────────────────────────────────────────────────────────────────┘
```

1. **ヘッダ部**:
   接続中のサーバー機種名、利用中のバックエンド、安全ステータス（Normal / Degraded / Failsafe）を表示。
2. **Fans パネル**:
   各ファンの現在回転数（RPM）とステータスをゲージ表示。
3. **Temperatures パネル**:
   CPU、PCH、NVMe などの各種温度センサーの現在値を表示。
4. **Control Status & Curve パネル**:
   現在の制御モード、出力 PWM 値、強制スコープ、適用中の温度ファンカーブを視覚的に描画。
5. **フッタ（キーヘルプ）**:
   利用可能なショートカットキーを常時表示。

## キーバインド一覧

| キー | 動作 |
|---|---|
| `q` / `Ctrl+C` | TUI を終了する（デーモンはそのまま動き続けます） |
| `a` | **iRMC Auto** モードに切り替え（OEM 強制解除） |
| `c` | **Curve** モード（ファンカーブ自動制御）に切り替え |
| `f` | **Fixed PWM**（PWM 固定値）設定ダイアログを開く |
| `r` | **Target RPM**（目標回転数 PI 制御）設定ダイアログを開く |
| `s` | **Scope**（PWM 強制範囲: `chassis` ⇔ `all`）をトグル切り替え |
| `m` | **Mode 選択メニュー**を開く |
| `Esc` | 開いているダイアログやメニューを閉じる / キャンセル |

---

## ダイアログ操作

### 1. Fixed PWM 設定 (`f` キー)

1. `f` キーを押すと入力ダイアログが表示されます。
2. 数字キー（または `↑` / `↓` キー）で希望の PWM 値（例: `30`）を入力します。
3. `Enter` キーを押すと即座にデーモンへ反映されます。
4. 中断したいときは `Esc` キーを押します。

### 2. Target RPM 設定 (`r` キー)

1. `r` キーを押すと回転数設定ダイアログが表示されます。
2. 基準ファン（デフォルト: `FAN CPU`）に対する目標 RPM（例: `2000`）を入力します。
3. `Enter` キーを押すと、デーモンが目標回転数に向けて自動で PWM を微調整する PI 制御を開始します。

### 3. PWM スコープのトグル (`s` キー)

`s` キーを押すたびに、画面下部の Scope 表示が以下のように切り替わります：
- **`Chassis`**: CPU ファンとリアファンのみを制御し、PSU ファンは iRMC 自動制御（静音）。
- **`All`**: PSU ファンを含むすべてのファンに強制 PWM を適用（冷却強化）。
